# My Resume Website — Nandan K S

A personal **Resume & Bio-data** website built as a single-page application using **HTML, CSS, and JavaScript**.  
All sections — Home, Resume, Bio-data, and Contact — are loaded dynamically without page reloads.  
Developed as part of a **Web Technology assignment** 

---

## 📌 Project Features

- ✔️ Developed a multi-page website including **Home**, **Resume**, and **Bio-Data** sections  
- ✔️ Created using:
  - **HTML** for page structure  
  - **CSS** for design and layout styling  
  - **JavaScript** for interactive features  
- ✔️ Designed with a clean, responsive interface  
- ✔️ Implemented simple and intuitive navigation  
- ✔️ Deployed on the cloud using **GitHub Pages**

---

## Project Structure

```
MyResume/
│
├── index.html      → Main HTML file (all sections included)
├── style.css       → All styling and layout
├── script.js       → Navigation logic and interactivity
└── README.md       → Project documentation
```

---

## Technologies Used

- **HTML5** — Page structure and semantic markup  
- **CSS3** — Styling, layout, and visual design  
- **JavaScript (Vanilla)** — Section switching and DOM manipulation  
- **Font Awesome** — Icon library (CDN)  
- **GitHub Pages** — Hosting platform  

---

## 🚀 Running the Project on Your Local Machine

1. Clone or download the repository to your computer.
2. Navigate to the project directory.
3. Locate and open the `index.html` file.
4. The website will launch in your default web browser.
